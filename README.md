# Superstore Sales Analysis
## 📌 Problem Statement
Retail businesses generate massive amounts of transactional data every day, but extracting meaningful insights from this data is a major challenge. The goal of this project is to analyze Superstore sales data to identify revenue-driving products, customer purchasing behavior, seasonal sales trends, and valuable customer segments.

This project focuses on:
* Understanding overall business performance
* Identifying top-performing categories and products
* Discovering customer purchasing patterns
* Performing customer segmentation using RFM Analysis
* Generating actionable business insights for decision-making

## 📂 Dataset Details
**Dataset Name:** Superstore Sales Dataset  
**Description:** The dataset contains historical transactional records of a retail superstore.

### Key Features
| Feature | Description |
| :--- | :--- |
| **Order ID** | Unique order identifier |
| **Order Date** | Date of purchase |
| **Customer ID** | Unique customer identifier |
| **Segment** | Customer segment type |
| **Category** | Product category |
| **Sub-Category** | Product sub-category |
| **Sales** | Revenue generated |
| **Profit** | Profit earned |
| **Quantity** | Number of products sold |
| **Region** | Sales region |

### Dataset Statistics
* **Total Transactions:** ~9,800 records
* **Unique Orders:** 4,922
* **Unique Customers:** 793
* **Total Revenue:** $2.26M+

## ⚙️ Approach

### 1. Data Preprocessing
* Removed missing/null values.
* Converted date columns into datetime format.
* Handled duplicate records.
* Feature engineering for time-series and RFM analysis.

### 2. Exploratory Data Analysis (EDA)
Performed detailed visual and statistical analysis to understand:
* Monthly sales trends and seasonality.
* Revenue distribution across regions.
* Product category and sub-category performance.

### 3. Customer Segmentation (RFM Analysis)
Implemented **RFM (Recency, Frequency, Monetary)** analysis to classify customers:
* **Recency:** Days since last purchase.
* **Frequency:** Total number of orders.
* **Monetary:** Total revenue generated by the customer.

### 4. Business Insights Generation
Actionable recommendations derived from customer behavior and demand patterns.

## 📊 Results & Insights

### 🔹 Overall Business Performance
* **Total Revenue:** $2,261,536.78
* **Average Order Value:** $459+
* **Sales Trends:** Significant spikes observed during **Q4 (November–December)**, indicating high holiday demand.

### 🔹 Top Revenue Drivers
* **Best Segment:** The **Consumer Segment** generated the highest revenue.
* **Best Sub-Categories:** **Phones** and **Chairs** are the top contributors to total sales.

### 🔹 RFM Segmentation Results
| Segment | Description | Count |
| :--- | :--- | :--- |
| **Champions** | High-value loyal customers | 242 |
| **Potential Loyalists** | Customers with future growth potential | - |
| **Needs Attention** | Customers with low engagement | - |
| **At Risk** | Previously active customers who may churn | 154 |

## 🚀 Business Recommendations
* **Customer Retention:** Launch targeted re-engagement campaigns for "At Risk" customers.
* **Loyalty Programs:** Introduce VIP rewards for "Champion" customers to maintain high LTV.
* **Seasonal Marketing:** Increase inventory and ad spend 1-2 months before the Q4 spike.
* **Cross-Selling:** Target "Potential Loyalists" with bundle offers in high-performing categories like Phones.
